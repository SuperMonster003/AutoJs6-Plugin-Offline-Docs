相机 (Camera)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 camera autojs6:camera, $autojs.camera autojs6:camera, $autojs.camera host.camera
状态 已支持 8 项 已支持 8 项 已支持 8 项 需授权 8 项
授权 - - - camera.control 8 项

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

camera 模块用于在脚本中使用 3-Prism Camera 插件的相机能力: 拍照 (可直接存为 JPEG 文件), 连续取帧做识别 (例如配合 ocr, barcode 或 YOLO 物体检测), 在 ui 布局或悬浮窗的 SurfaceView 中显示预览, 以及手电, 闪光, 变焦, 曝光与对焦控制. 相机由插件打开, 帧经共享内存交给 AutoJs6, 画面与照片只在插件和 AutoJs6 之间传递.

从 AutoJs6 6.8.1 (构建 6641) 起, 本模块由外置 3-Prism Camera 插件 (AutoJs6-Plugin-Three-Prism-Camera) 1.0.0 及以上版本提供, 宿主不包含相机实现. 调用前需在插件中心安装并启用插件. 插件未安装时方法抛出 code 为 PLUGIN_NOT_INSTALLED 的 CameraError, 被禁用时为 PLUGIN_DISABLED, 插件要求更高版本的 AutoJs6 时为 HOST_VERSION_TOO_LOW. camera.isAvailable 可预先探测, 不会抛出.

本模块在 Rhino 中注册为全局名称 camera, 并提供 $camera 别名, 二者指向同一对象. 本页的签名与同步返回值描述 Rhino. Node.js 主线程与 Worker 通过 require('autojs6:camera') (或 $autojs.camera) 使用, Bun 通过 host.camera (需授权 camera.control) 使用, 成员, 选项, 错误码与关闭原因相同, 但全部返回 Promise; 这些运行时没有可用于预览的 View, preview 与 stopPreview 以 UNSUPPORTED 拒绝, 照片用 camera.recycle(image) 回收. 参阅 运行时 API.

帧的生命周期: analyze 回调里的 img 只在回调执行期间有效, 回调返回后立即回收, 之后再访问会抛出 "图像已回收". 要在回调之外使用, 先调用 img.clone() 得到副本, 用完后自行 recycle(). 回调耗时超过帧间隔时新帧会被丢弃而不是排队, 丢弃数量见 state().dropped 与 "dropped" 事件.

// 实时扫码: 帧只在回调里有效
let session = camera.open({ resolution: '1280x720' });
session.analyze((img, meta) => {
    let codes = barcode.detect(img);
    if (codes.length > 0) {
        toastLog(codes[0].rawValue);
        session.close();
    }
});
events.on('exit', () => session.close());

准备工作#

  1. 在插件中心安装并启用 3-Prism Camera. 插件为 arm64-v8a, armeabi-v7a, x86_64 与 x86 各提供一个安装包, 另有适用于全部设备的 universal 安装包; 支持 Android 7.0 (API 24) 及以上.
  2. 授予插件相机权限. 相机在插件进程内打开, 因此相机权限由插件自己持有, AutoJs6 的相机权限不能代替. 可以在插件的设置页授权, 也可以由脚本调用 camera.requestPermission 打开插件的授权页. 插件缺少权限时打开相机失败于 PERMISSION_DENIED.
  3. 会话打开期间, 插件以相机类型的前台服务运行并显示一条通知, 这样 AutoJs6 退到后台或熄屏后仍能继续取帧; 会话关闭后通知随即消失. Android 13 及以上需要允许插件发送通知才能看到它.

插件申请网络权限只用于设置页的检查更新: 读取 AutoJs6 官方插件索引, 与已安装版本的 versionCode 比较, 有新版本时提示下载; 打开设置页时自动检查, 每 12 小时最多一次, 可以在设置页关闭. 相机画面, 照片与设置不会离开设备, 插件也不申请存储权限, 照片只在指定 path 时由 AutoJs6 写入文件.

默认值与插件设置页#

camera.open 与 camera.capture 省略 facing / id, resolution 或 fps 时, AutoJs6 不发送对应的键, 由插件按其设置页的默认值补齐:

  • 镜头: 设置页的 "默认镜头", 用户未修改时为后置镜头.
  • 分析分辨率: 设置页的默认分析分辨率, 用户未修改时为 640x480.
  • 帧率: 设置页的默认帧率, 用户未修改时由设备决定.

analyze 省略的分辨率与帧率沿用 open 的值. 实际生效的镜头, 分辨率与帧率以 state 与帧的 meta 为准, 脚本需要固定值时应显式传入.

线程与调用形式#

插件的绑定在 AutoJs6 的主线程上应答, 因此 UI 线程 ("ui"; 脚本的界面回调) 不能同步等待插件. 各方法在 UI 线程上的行为如下:

  • 发现类调用 isAvailable, capabilities, list 与 requestPermission 有三种形式, 返回形式只取决于线程与参数, 与插件是否已连接无关:
    • 在 UI 线程上不传回调: 返回 Promise, 以同步形式的返回值兑现, 失败时以 CameraError 拒绝 (isAvailable 只兑现).
    • 在任意线程上以函数为唯一参数: 立即返回 undefined, 之后在调用它的脚本线程上调用 callback(value, null) 或 callback(null, error), 与 http 的回调形式一致.
    • 在其他线程上不传回调: 等待插件应答后同步返回.
    • 参数为 undefined 或 null 视为未传回调, 其他参数抛出 INVALID_ARGUMENT.
  • camera.open 在 UI 线程上检查选项后立即返回会话, 并在后台连接插件与打开相机; 连接期间 state().open 为 false, 在 UI 线程上调用的 preview, stopPreview, analyze, stopAnalysis, torch, flashMode, zoom, zoomLinear 与 exposure 先检查参数, 再按调用顺序排队, 打开后依次执行. 排队的调用或打开本身失败时以会话的 "error" 事件报告 (没有监听器时输出到控制台), 打开失败后会话以原因 error 关闭. 在其他线程上 open 等会话打开后才返回.
  • 连接期间在 UI 线程上调用 zoomState 与 exposureState 抛出 INVALID_ARGUMENT, 因为它们需要镜头的应答: 在 state().open 为 true 之后再读取.
  • camera.capture, 会话的 capture 与 focusAt 在 UI 线程上抛出 INVALID_ARGUMENT, 请在 threads.start 的线程中调用, 或在 UI 线程上使用 captureAsync.

方向与镜像#

  • 帧默认按屏幕方向旋正 (upright: true), 帧的 meta.rotationDegrees 给出旋转角度; upright: false 时帧保持传感器方向.
  • 帧与拍照默认不镜像, 前置镜头也一样, 因此识别结果与真实画面一致; mirror: true 时帧与拍照同时水平镜像.
  • 前置镜头的预览总是镜像 (与系统相机一致), 不受 mirror 影响; state().previewMirrored 表示当前预览是否镜像.
  • 拍照得到的 JPEG 保留 EXIF 方向, AutoJs6 解码时按 EXIF 旋转, 因此返回的图像与写入的文件一致.

独占与 CAMERA_BUSY#

整个插件同一时间只有一个相机会话, 可以是某个脚本的会话, 也可以是插件自己的取景页. 已有会话时 camera.open 失败于 CAMERA_BUSY, 错误的 details.holder 指出占用者: 脚本的路径, 或 pluginUi (插件的取景页). 取景页显示正在使用相机的脚本并提供 "停止此脚本" 按钮; 用户按下后插件关闭该会话, 脚本先收到原因为 pluginUi 的 "close" 事件, 监听器执行后该脚本被停止. 其他应用占用相机时为 CAMERA_UNAVAILABLE.

  • returns { boolean | Promise } - 插件是否已安装, 已启用且与当前 AutoJs6 兼容; 在 UI 线程上为兑现该值的 Promise

探测插件可用性, 不抛出插件错误. 返回 true 不表示插件已获得相机权限, 权限状态见 capabilities 的 permissionGranted.

[m] requestPermission#

camera.requestPermission()#

6.8.1 Overload 1/2

  • returns { boolean | Promise } - 插件此后是否持有相机权限; 在 UI 线程上为兑现该值的 Promise

插件已持有相机权限时立即返回 true. 否则打开插件的授权页, 等待用户返回 (最多两分钟) 后返回插件是否持有权限. 打开授权页要求 AutoJs6 处于前台, 否则抛出 UI_REQUIRES_FOREGROUND.

  • callback { (granted: boolean | null, error: CameraError | null) => void } - 结果回调, 在调用线程上执行
  • returns { void }

[m] list#

camera.list()#

6.8.1 Overload 1/2

  • returns { Object[] | Promise } - 镜头列表; 在 UI 线程上为兑现该数组的 Promise

每个镜头为 { id, facing, hasFlash, sensorRotation, zoomRange, exposureRange, exposureStep, analysisResolutions, captureResolutions }: facing 为 "back", "front" 或 "external", zoomRange 与 exposureRange 为 [min, max], 两个分辨率列表为 "宽x高" 字符串. id 可传给 open 的 id 选项.

camera.list(callback)#

6.8.1 Overload 2/2 Async

  • callback { (cameras: Object[] | null, error: CameraError | null) => void } - 结果回调, 在调用线程上执行
  • returns { void }
camera.list((cameras, err) => {
    if (err) return console.error(err.code, err.message);
    cameras.forEach(c => console.log(c.id, c.facing, c.analysisResolutions.join(', ')));
});

[m] open#

camera.open(options?)#

6.8.1

  • [ options ] {{
    • facing?: "back" | "front";
    • id?: string;
    • resolution?: string;
    • fps?: number;
    • upright?: boolean;
    • mirror?: boolean;
    • flashMode?: "auto" | "on" | "off";
  • }} - 会话选项
  • returns { CameraSession } - 相机会话

独占打开相机并返回会话. 选项:

  • facing 与 id 二选一, 都省略时由插件设置页的默认镜头决定 (见 默认值与插件设置页).
  • resolution: 分析的目标分辨率, 如 "1280x720"; 实际尺寸见 state().resolution 与帧的 meta. 省略时取设置页的默认值.
  • fps: 目标帧率, 省略时取设置页的默认值.
  • upright: 帧是否按屏幕方向旋正, 默认 true.
  • mirror: 帧与拍照是否镜像, 默认 false; 不影响预览 (见 方向与镜像).
  • flashMode: 拍照的闪光模式, 默认 "auto".

在 UI 线程上调用时立即返回, 会话在后台连接 (见 线程与调用形式); 在其他线程上会话打开后才返回. 会话在 close, 脚本结束或插件关闭它时结束; 脚本结束时 AutoJs6 自动关闭会话.

AutoJs6 在后台或手机停在锁屏时 (Android 11 及以上), 系统不允许插件使用相机: open 照常返回会话, 但收不到帧, 会话先触发 CAMERA_DISABLED 的 "error" 事件, 再以原因 policy 关闭. 需要在后台取帧时, 在 AutoJs6 位于前台时打开会话, 已打开的会话在 AutoJs6 退到后台或熄屏后照常出帧.

[m] capture#

camera.capture(options?)#

6.8.1

  • [ options ] {{
    • ui?: boolean;
    • facing?: "back" | "front";
    • id?: string;
    • path?: string;
    • quality?: number;
    • flashMode?: "auto" | "on" | "off";
    • resolution?: string;
    • mirror?: boolean;
  • }} - 拍照选项
  • returns { ImageWrapper | null } - 照片; 用户离开取景页时为 null

一步拍照. 本脚本已有打开的会话时使用该会话的镜头; 否则临时打开相机, 拍照后关闭. ui: true 时打开插件的取景页由用户拍照 (要求 AutoJs6 处于前台, 否则 UI_REQUIRES_FOREGROUND), 用户未拍照就离开时返回 null, 取景页等待用户, 没有期限.

指定 path 时 AutoJs6 把 JPEG 原样 (保留 EXIF) 写入该路径, 相对路径按脚本工作目录解析; 写入先在同一目录生成隐藏的临时文件, 完成后改名为目标文件. quality 为 JPEG 质量 (1 - 100, 默认 95). 返回的图像是普通的 ImageWrapper, 不受 帧的生命周期 限制, 用完后由脚本调用 recycle() 回收 (与 images.captureScreen 返回的受截图模块管理的图像不同).

不能在 UI 线程上调用, 请使用 captureAsync.

let img = camera.capture({ path: files.join(files.getSdcardPath(), 'prism.jpg') });
toastLog(img.getWidth() + 'x' + img.getHeight());
img.recycle();

// 让用户在取景页拍一张
let shot = camera.capture({ ui: true });
if (shot === null) toastLog('已取消');

[C] CameraError#

CameraError#

6.8.1

相机失败的错误类, 通过 camera.CameraError 访问, 继承 Error. e instanceof camera.CameraError 可判断错误类型.

  • name: "CameraError".
  • code: 错误码, 见下表.
  • message: 当前应用语言的说明; 插件或选项检查给出更多细节时附在括号中 (细节不翻译).
  • details: { holder, cameraId, limit, reason }, holder 为占用者 (CAMERA_BUSY), cameraId 为相关镜头 (CAMERA_UNAVAILABLE), limit 为超出的上限 (INVALID_ARGUMENT, LIMIT_EXCEEDED), reason 为未翻译的细节; 不适用的字段为 null.
  • toString() 返回 CameraError [code]: message.
错误码 含义
PLUGIN_NOT_INSTALLED 未安装 3-Prism Camera 插件
PLUGIN_DISABLED 插件已在插件中心停用
HOST_VERSION_TOO_LOW 插件要求更高版本的 AutoJs6
PERMISSION_DENIED 插件没有相机权限, 可调用 requestPermission
CAMERA_BUSY 其他会话或插件的取景页正在使用相机, details.holder 指出占用者
CAMERA_UNAVAILABLE 没有符合 facing / id 的镜头, 或其他应用正在使用相机
CAMERA_DISABLED 当前不允许使用相机: AutoJs6 在后台或锁屏时打开会话 (以会话的 "error" 事件报告, 随后以 policy 关闭), 设备策略或系统的相机隐私开关
UI_REQUIRES_FOREGROUND 打开取景页或授权页时 AutoJs6 不在前台
UNSUPPORTED 插件或镜头不支持该功能, 或插件契约版本不兼容
INVALID_ARGUMENT 选项缺失, 类型错误或超出范围, 或在不允许的线程上调用
SESSION_CLOSED 会话已关闭, 插件进程退出或绑定丢失
TIMEOUT 调用或拍照结果未在期限内到达
LIMIT_EXCEEDED 结果超出上限, 如超过 64 MiB 的 JPEG
INTERNAL 其他错误 
try {
    camera.open();
} catch (e) {
    if (e instanceof camera.CameraError && e.code === 'CAMERA_BUSY') {
        toastLog('相机正被占用: ' + e.details.holder);
    } else {
        throw e;
    }
}

[m#] on#

on(event, listener)#

6.8.1

  • event { string } - 事件名
  • listener { Function } - 监听器
  • returns { CameraSession }

注册监听器. once 形态相同, 只触发一次; off(event, listener?) 移除监听器, 省略 listener 时移除该事件的全部监听器. 事件:

事件 参数 说明
frame (img, meta) 每一帧; img 只在监听器执行期间有效
dropped (count, lastSeq) 有帧被丢弃时 (分批报告), count 为本次分析累计丢弃数
error (err) 不结束会话的失败, UI 线程上排队调用的失败, 以及会话因相机被禁用而以 policy 关闭之前的 CAMERA_DISABLED, err 为 CameraError

session.on('close', (reason) => console.log('会话结束:', reason));
