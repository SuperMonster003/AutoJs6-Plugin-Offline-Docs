工作表对象 (Sheet)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 Sheet 对象 autojs6:xlsx autojs6:xlsx host.xlsx
状态 已支持 64 项 已支持 64 项 已支持 64 项 需授权 64 项
授权 - - - xlsx.control 64 项

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

Sheet 是 Workbook#sheet, Workbook#addSheet 与 Workbook#copySheet 返回的工作表对象, 指向打开的工作簿中的一个工作表. 用它读取行与单元格, 写入值与公式, 插入与删除行列, 排序, 设置样式与版式, 添加批注, 超链接, 图片, 条件格式与数据有效性.

每个方法都有同步形态与 Async 形态, 参数与结果一致, 规则同 xlsx 模块; 工作表的方法都不报告进度. 失败时抛出 (或拒绝为) XlsxError, 与单元格有关时错误的 sheet 与 ref 指出位置.

修改作用于插件内存中的工作簿, 调用 Workbook#save 后才写入文件. 行号与列号从 1 计, 列可以写作字母或数字, 范围为 A1 形式, 见 行列编号与数据模型. csv 与 tsv 工作簿也能设置样式与版式, 但保存为 csv 或 tsv 时只写出值, 见 Workbook#save.

以 stream 模式打开的工作簿中, 属性与 read, eachRow, cell, find, merges 可用; 各修改方法失败于 READ_ONLY, conditionalFormats 与 validations 失败于 UNSUPPORTED. 见 读取模式与大表.

let wb = xlsx.open('./scores.xlsx');
try {
    let sheet = wb.sheet('成绩');
    console.log(sheet.toString(), sheet.dimension); // Sheet { name: 成绩 } A1:C31
    sheet.append([['合计', null, { f: 'SUM(C2:C31)' }]]);
    sheet.sort('C', { desc: true, hasHeader: true, range: 'A1:C31' });
    sheet.setStyle('A1:C1', { font: { bold: true }, fill: '#DDEBF7' });
    sheet.freeze(1);
    wb.save();
} finally {
    wb.close();
}

Sheet

[@] Sheet#

6.8.1

工作表对象. 不能用 new 构造, 只由 Workbook 的方法产生. 同一工作表总是对应同一个对象.

工作表对象按名称指向工作表: Workbook#renameSheet 之后 name 随之改变; 工作表被 Workbook#removeSheet 删除后, 对它的调用与属性读取失败于 SHEET_NOT_FOUND (消息形如 "the sheet 'x' was removed"). 工作簿关闭后的调用失败于 SESSION_CLOSED.

[p#] name#

6.8.1

  • { string }

工作表名称. 只读, 改名后随之改变.

[p#] index#

6.8.1

  • { number }

从 1 计的序号. 只读.

index, rows, cols 与 dimension 是实时属性: 每次读取都向插件查询一次, 反映当前 (含未保存的修改) 的内容. 在循环中反复使用时, 先存入变量.

在 Node.js 与 Bun 中这四个属性同样每次读取都查询一次, 但读取结果是 Promise, 用 await sheet.rows 取得数值, 查询排在同一工作簿之前的调用之后执行. 见 运行时 API.

[p#] rows#

6.8.1

  • { number }

最后一个有内容的行号, 空表为 0. 只读.

[p#] cols#

6.8.1

  • { number }

最后一个有内容的列号, 空表为 0. 只读.

[p#] dimension#

6.8.1

  • { string | null }

已用范围, 例如 'A1:F120', 空表为 null. 只读.

[m#] read#

6.8.1

  • [ options ] { ReadOptions } - 读取选项, 不接受 sheet

读取本工作表的行. 默认返回数组的数组, header: true 时返回对象数组, 规则同 xlsx.read. 结果一次性放入脚本内存, 大表请用 eachRow.

let rows = sheet.read({ header: true, range: 'A1:D50' });

[m#] eachRow#

sheet.eachRow(callback, options?)#

6.8.1

  • callback { (rows: any[][] | object[], startRow: number) => boolean | void } - 逐批接收行的回调
  • [ options ] {{
    • batch?: number;
    • from?: number;
    • to?: number;
    • range?: string;
    • header?: boolean;
    • cells?: boolean;
    • formatted?: boolean;
    • blankRows?: boolean;
    • trim?: boolean;
  • }} - 读取选项
  • returns { number } - 交给回调的行数

分批读取本工作表的行, 每批调用一次 callback. 内存占用与表的大小无关, 适合读取大表.

  • rows 为本批的行, 形态同 read; startRow 为本批第一行的工作表行号.
  • callback 返回 false 时停止读取, 返回其他值 (或不返回) 时继续.
  • batch 为每批的行数, 1 至 1000, 默认 1000. 其他选项同 ReadOptions, 不接受 sheet 与 limit.
  • 回调在脚本线程执行. 回调抛出的错误使本次调用以该错误失败.
  • callback 不是函数时失败于 INVALID_ARGUMENT.
let total = 0;
let count = sheet.eachRow((rows, startRow) => {
    rows.forEach(r => total += r['金额'] || 0);
    console.log('已读到第 ' + (startRow + rows.length - 1) + ' 行');
}, { header: true, batch: 500 });
console.log(count, total);

[m#] cell#

sheet.cell(ref, options?)#

6.8.1 Overload 1/2

  • ref { string } - 单元格的 A1 引用
  • [ options ] { { cells?: boolean; formatted?: boolean }} - 读取选项
  • returns { any | CellDetail } - 单元格的值

读取一个单元格. 默认返回值 (规则同 行列编号与数据模型), 空单元格为 null; formatted: true 返回显示文本; cells: true 返回 CellDetail, 单元格在合并区域内时带 merged. cells 与 formatted 不能同时为 true.

console.log(sheet.cell('B2')); // 3
console.log(sheet.cell(2, 'C', { formatted: true })); // 1.50
let detail = sheet.cell('A1', { cells: true });
console.log(detail.t, detail.style, detail.merged);

[m#] set#

sheet.set(ref, value)#

6.8.1

  • ref { string } - 单元格的 A1 引用
  • value { any | {{ v?: any; f?: string; style?: number | StyleSpec }} } - 值, 或带公式与样式的对象
  • returns { void }

写入一个单元格.

  • value 为数字, 字符串, 布尔值, Date 或 null 时按字面写入, 规则同 行列编号与数据模型. 字符串总是写为文本, 以 = 开头也不作为公式. null 与 undefined 清除值, 保留样式.
  • value 为对象时只接受 v, f 与 style 三个键 (其他键失败于 INVALID_ARGUMENT): f 写入公式 (= 可省略), 同时给出的 v 作为公式的缓存结果; style 为样式 id 或 StyleSpec, 效果同 setStyle.
  • 公式为空或无法解析时失败于 FORMULA_ERROR. 公式在保存时按 evaluate 计算, 见 公式.
sheet.set('A1', '标题');
sheet.set('B2', new Date());
sheet.set('D2', { f: 'B2*C2', style: { numFmt: '0.00' } });
sheet.set('E2', '=1+1'); // 文本 "=1+1".

[m#] setRows#

sheet.setRows(startRow, rows, options?)#

6.8.1

  • startRow { number } - 写入的第一行的行号
  • rows { any[][] | object[] } - 行
  • [ options ] {{
    • style?: number | StyleSpec;
    • dateFormat?: string;
    • formulas?: boolean;
  • }} - 写入选项
  • returns { number } - 写入的行数

从 startRow 行的 A 列起写入多行, 覆盖原有的值.

  • 行的写法同 xlsx.write: 数组行按列顺序写入, 单元格可以是 { f: '...' } 公式. 对象行按第一个对象行的键的顺序写入各列, 不写表头行.
  • style 为样式 id 或 StyleSpec, 叠加到写入的每个单元格上.
  • dateFormat 为写入日期的数字格式, 默认 yyyy-mm-dd hh:mm:ss.
  • formulas: true 时以 = 开头的字符串作为公式写入.
sheet.setRows(2, [
    ['钢笔', 3, 1.5, { f: 'B2*C2' }],
    ['笔记本', 2, 12, { f: 'B3*C3' }],
], { style: { font: { name: '微软雅黑' } } });

[m#] append#

sheet.append(rows)#

6.8.1

  • rows { any[][] | object[] } - 行
  • returns { number } - 写入的行数 (含新写的表头行)

在最后一个有内容的行之后追加行, 不接受选项.

  • 数组行按列顺序从 A 列写入.
  • 对象行: 工作表已有内容时, 按第 1 行的文本把对象的键对应到列 (对不上的键被忽略); 工作表为空时, 先以第一个对象行的键写入表头行.

需要样式, 日期格式或公式选项时, 用 rows 求出起始行再调用 setRows.

sheet.append([{ 日期: new Date(), 事件: '启动' }]);
