工作簿对象 (Workbook)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 Workbook 对象 autojs6:xlsx autojs6:xlsx host.xlsx
状态 已支持 30 项 已支持 30 项 已支持 30 项 需授权 30 项
授权 - - - xlsx.control 30 项

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

Workbook 是 xlsx.open 与 xlsx.create 返回的工作簿对象, 对应插件进程中一个打开的工作簿. 用它取得 工作表, 管理工作表, 注册样式, 重算公式并保存到文件.

每个方法都有同步形态与 Async 形态, 参数与结果一致, 规则同 xlsx 模块: 同步形态阻塞当前脚本线程, Async 形态返回带 cancel() 的 Promise. 失败时抛出 (或拒绝为) XlsxError. 只有 saveAsync 报告进度.

修改都作用于插件内存中的工作簿, 调用 save 后才写入文件; 不保存就 close 时丢弃全部修改. 同一工作簿的调用在插件中依次执行.

以 stream 模式打开的工作簿 (mode 为 'stream') 只能读取: info, sheetNames, sheet 与工作表的读取方法可用, 工作表操作, createStyle, recalc 与 save 失败于 READ_ONLY. 见 读取模式与大表.

let wb = xlsx.open('./sales.xlsx');
try {
    console.log(wb.toString()); // Workbook { format: xlsx, mode: full }
    console.log(wb.sheetNames()); // [ '一月', '二月' ]
    let sheet = wb.addSheet('汇总', { index: 1 });
    sheet.setRows(1, [['月份', '合计'], ['一月', { f: "SUM('一月'!C:C)" }], ['二月', { f: "SUM('二月'!C:C)" }]]);
    wb.save();
} finally {
    wb.close();
}

Workbook

[@] Workbook#

6.8.1

工作簿对象. 不能用 new 构造, 只由 xlsx.open, xlsx.create 及其 Async 形态产生.

每个打开的工作簿占用一个句柄, 每个脚本的工作簿与 写出器 合计至多 16 个 (超出时失败于 TOO_MANY_HANDLES). 工作簿在插件中保持打开, 直到调用 close 或脚本结束 (此时自动关闭, 不保存). 30 分钟内没有调用且没有进行中的操作时, 插件关闭该工作簿, 之后的调用失败于 SESSION_CLOSED.

[p#] format#

6.8.1

  • { 'xlsx' | 'xlsm' | 'xls' | 'csv' | 'tsv' }

打开或新建时的文件格式. 以其他格式 保存 不改变此属性.

[p#] mode#

6.8.1

  • { 'full' | 'stream' }

打开时实际采用的载入方式. 选项 mode 为 'auto' 时为插件按表的大小选定的方式, xlsx.create 新建的工作簿为 'full'. 见 读取模式与大表.

是否已调用 close 关闭.

[m#] sheet#

wb.sheet(nameOrIndex)#

6.8.1

  • nameOrIndex { string | number } - 工作表名称, 或从 1 计的序号
  • returns { Sheet }

取得工作表对象. 工作表不存在时失败于 SHEET_NOT_FOUND. 同一工作表总是返回同一个对象.

工作表对象按名称指向工作表: renameSheet 之后它的 name 随之改变, removeSheet 之后对它的调用失败于 SHEET_NOT_FOUND.

let wb = xlsx.open('./report.xlsx');
let first = wb.sheet(1);
console.log(first === wb.sheet(first.name)); // true
wb.close();

[m#] addSheet#

wb.addSheet(name, options?)#

6.8.1

  • name { string } - 新工作表的名称
  • [ options ] { { index?: number }} - index 为新工作表的位置 (从 1 计), 默认放在最后
  • returns { Sheet }

新建一个空的工作表并返回它. index 超出 1 至工作表数加 1 时失败于 INVALID_ARGUMENT.

工作表名称的规则 (同样用于 renameSheet 与 copySheet): 1 至 31 个字符; 不含 /, ?, *, [, ], : 与反斜杠; 不以 ' 开头或结尾; 不区分大小写地与其他工作表不同名. 不符合时失败于 INVALID_ARGUMENT.

csv 与 tsv 工作簿可以添加工作表, 但保存为 csv 或 tsv 时只写出一个工作表, 见 save.

[m#] createStyle#

wb.createStyle(spec)#

6.8.1

  • spec { StyleSpec } - 样式规格
  • returns { number } - 样式 id

在工作簿中登记一个样式, 返回它的 id. 这个 id 可以传给本工作簿的 Sheet#set, Sheet#setRows 的 style 与 Sheet#setStyle, 效果同直接传入该规格: 叠加在单元格已有的样式上, 只改规格中给出的键. 同一样式反复使用时, 先登记再传 id 比每次传规格对象更快.

读取选项 cells: true 得到的 CellDetail 的 style 是文件中已有样式的 id, 把它传给上述方法时整体替换单元格的样式, 可用于把一个单元格的样式复制到其他单元格.

样式 id 只在本工作簿中有效. 一个工作簿中不同样式的数目有上限, 见 StyleSpec.

let wb = xlsx.open('./report.xlsx');
let sheet = wb.sheet(1);
let warn = wb.createStyle({ font: { color: '#C00000', bold: true }, fill: '#FCE4D6' });
sheet.find('逾期').forEach(hit => sheet.setStyle(hit.ref, warn));
// 把 A1 的样式整体复制到 A2:A10.
sheet.setStyle('A2:A10', sheet.cell('A1', { cells: true }).style);
wb.save();
wb.close();

[m#] recalc#

wb.recalc()#

6.8.1

  • returns { { formulas: number; evaluated: number; warnings: string[] }} - 公式单元格数, 得到新计算结果的个数, 警告 (英文)

重算全部工作表的全部公式, 更新缓存的计算结果, 之后读取公式单元格得到新的结果. 不论有无改动都计算. 不能计算的公式按 公式 中的规则处理并记入 warnings, 它们不计入 evaluated.

重算只改变内存中的工作簿, 需要 save 才写入文件. 保存时插件本来就会在有值的改动后计算公式, 所以 recalc 主要用于在保存前读取计算结果, 或用于修正其他程序留下的缓存值.

let wb = xlsx.open('./budget.xlsx');
let sheet = wb.sheet('明细');
sheet.set('B2', 1200);
let r = wb.recalc();
console.log(r.formulas, r.evaluated, r.warnings);
console.log(wb.sheet('汇总').cell('B1')); // 新的合计.
wb.save();
wb.close();

[m#] save#

wb.save(output?, options?)#

6.8.1

  • [ output ] { string } - 输出路径, 省略时保存回打开的文件
  • [ options ] {{
    • format?: 'xlsx' | 'xlsm' | 'xls' | 'csv' | 'tsv';
    • password?: string | null;
    • evaluate?: boolean;
  • }} - 保存选项
  • returns { SheetResult }

把工作簿写入文件. 只给一个对象参数时, 它被视为 options, 即 wb.save({ password: 'x' }) 保存回打开的文件.

  • 输出: 省略 output 时保存回打开的文件. xlsx.create 新建的工作簿没有文件, 必须给出 output, 否则失败于 INVALID_ARGUMENT (消息为 "save needs an output path for a workbook made by xlsx.create"). 文件先写到临时文件, 成功后才替换目标, 失败或取消时目标保持原样.
  • 格式: 依次取 format, output 的扩展名, 工作簿打开时的格式, 最后为 'xlsx'.
  • 密码: 省略 password 时沿用打开时的密码 (未加密的仍不加密); 为非空字符串时以它加密; 为 '' 或 null 时去掉加密. 加密方式见 加密与密码.
  • 计算: evaluate 默认 true, 有值的改动后保存时计算公式并写入缓存值; 为 false 时跳过计算, 并设置打开时重算. 见 公式.

保存不改变工作簿本身: 之后的修改与保存仍基于内存中的工作簿, format 也不变.

以其他格式保存:

  • xlsx 与 xls 互存: 写出转换后的副本, 保留工作表 (顺序, 名称, 可见性, 活动工作表), 值, 公式与缓存结果, 富文本, 样式, 合并区域, 列宽, 行高, 冻结窗格, 自动筛选, 超链接, 批注, 图片, 数据有效性, 定义名称, 打印区域, 网格线, 从右到左与 1904 日期系统. 保存为 xls 时颜色换为调色板中最接近的颜色, 超出 65,536 行或 256 列, 或者需要超过 4,000 个样式时失败于 LIMIT_EXCEEDED; xls 无法容纳的公式 (较新的函数, 结构化引用) 保留缓存值; 条件格式, 表格 (单元格保留), 数据透视表, 图表等绘图, 工作表保护与宏不保留. 这些都在 warnings 中说明.
  • xlsm: 打开的 xlsm 保存为 xlsm 时保留宏; 保存为 xlsx 时去掉宏并给出警告. 不含宏的工作簿 (包括新建的) 保存为 xlsm 失败于 UNSUPPORTED.
  • csv 与 tsv: 只写出第一个可见的工作表, 有多个工作表时给出警告; 不保存样式与版式, 公式写出其计算结果. 打开的 csv 或 tsv 沿用文件的编码, BOM 与行尾 (同一格式时还沿用分隔符), 其他工作簿写出带 BOM 的 UTF-8. 只在最后一行之后追加了行时, 原有内容按字节保留, 新行按文件的编码与分隔符追加. 输出总是明文: 打开时的密码被去掉并在 warnings 中说明, 显式给出非空的 password 失败于 UNSUPPORTED.
let wb = xlsx.open('./data.xlsx', { password: 'old' });
try {
    wb.sheet(1).set('A1', '已核对');
    wb.save(); // 沿用密码 'old'.
    wb.save('./data-plain.xlsx', { password: null }); // 去掉加密的副本.
    let r = wb.save('./data.xls'); // 按扩展名保存为 xls.
    r.warnings.forEach(w => console.warn(w));
} finally {
    wb.close();
}

[m#] saveAsync#

wb.saveAsync(output?, options?)#

6.8.1 Async

  • [ output ] { string } - 输出路径, 省略时保存回打开的文件
  • [ options ] { { format?: string; password?: string | null; evaluate?: boolean; onProgress?: Function }} - 保存选项
  • returns { Promise<SheetResult> }

与 save 相同, 另外接受 onProgress. 进度的 stage 为 'save', current 与 total 为已写出的行数与总行数, 写完后报告一次 100. 见 Progress.

let wb = xlsx.open('./big.xlsx');
wb.saveAsync('./big-copy.xls', {
    onProgress: p => console.log(p.stage, p.percent < 0 ? '?' : p.percent + '%'),
}).then(r => {
    console.log(r.path);
    wb.close();
}, e => {
    console.error(e.toString());
    wb.close();
});
