video 模块用于在脚本中录屏, 以及借助 3-Slate Studio 插件加工视频: 按时间裁剪, 拼接, 变速, 缩放 / 旋转 / 裁切 / 翻转, 文字与图片叠加, 抽帧与缩略图, 转 GIF, 抽取或去除音轨, 转码, 多轨时间线合成 (转场, 叠加与字幕) 以及字幕烧录. 音频的录制与加工见 音频 (Audio).

本模块自 AutoJs6 6.8.1 起提供. 录屏 (video.record) 由 AutoJs6 自己完成, 不需要插件. 其余加工方法由外置的 3-Slate Studio 插件 (AutoJs6-Plugin-Three-Slate-Studio) 1.0.0 及以上版本执行: AutoJs6 检查参数并补全默认输出路径, 再把请求交给插件, 插件在自己的进程中编解码并写出文件. 插件缺失时加工方法抛出 (或以 Promise 拒绝) code 为 PLUGIN_UNAVAILABLE 的 MediaStudioError, 其消息为插件中心的本地化缺插件提示; 插件被禁用或未授权时为 PLUGIN_DISABLED; 插件版本或契约不兼容时为 PLUGIN_INCOMPATIBLE. video.isAvailable 可预先探测. 插件的安装, 权限与界面见 3-Slate Studio.

本模块在 Rhino 中注册为全局名称 video, 并提供 $video 别名, 二者指向同一对象. audio 模块与它共用任务表, 错误类型与参数约定. 本页的签名与同步返回值描述 Rhino; Node.js 与 Bun 见 Node.js 与 Bun.

let clip = video.trim('/sdcard/Movies/a.mp4', { start: 2000, duration: 5000 });
let gif = video.toGif(clip.path, { fps: 10, width: 480 });
console.log(gif.path, gif.sizeBytes);

准备工作#

  1. 在插件中心安装并启用 3-Slate Studio. 安装向导把它列在 "工具" 分类中.
  2. 授予插件 "所有文件访问" 权限. 插件按脚本给出的路径直接读写文件, 默认输出目录也位于共享存储, 插件未获授权时加工失败于 STORAGE_PERMISSION_DENIED, 同时打开插件的授权页面 (每分钟至多一次). video.frame 不留下文件, 但同样需要该权限: 插件先把画面写成默认输出目录中的隐藏临时图片, 再由 AutoJs6 读取并删除. 输入与输出都位于插件私有目录 (Android/data/io.github.supermonster003.autojs6.plugin.three.slate.studio/) 时不需要该权限.
  3. 录屏前先调用 images.requestScreenCapture 取得截图会话, 见 video.record.

参数约定#

  • 输入与输出都是文件路径. 相对路径按脚本工作目录解析 (与 files.path 相同), 不接受 content://, file:// 等 URI.
  • 必需参数之后的参数按类型识别: 字符串为输出路径, 对象为选项, null 与 undefined 表示使用默认输出. 输出路径与选项的先后顺序不限, 但各至多一个, 出现第二个字符串或第二个对象时以 INVALID_OPTIONS 拒绝. 本页按常见顺序书写签名, 例如 video.trim(src, options?, output?) 也可以写作 video.trim(src, output, options).
  • 选项像 JSON.stringify 一样序列化后交给插件, 回调函数 onProgress 被单独取出. 未知的选项键按名称以 INVALID_OPTIONS 拒绝, 类型或取值范围错误同样为 INVALID_OPTIONS, 错误消息写明键名; 输入个数, GIF 帧数等上限为 LIMIT_EXCEEDED. 时间以毫秒计, 除另有说明外须为整数.
  • 显式输出路径的扩展名须与操作相符: 视频为 .mp4, extractAudio 为 .m4a, .wav, .flac 或 .ogg, 图片为 .png, .jpg 或 .jpeg, GIF 为 .gif (不区分大小写), 否则为 UNSUPPORTED_FORMAT. 音频与图片的扩展名在省略 format 选项时决定输出格式, 两者同时给出时须一致. 输出文件已存在, 或者正被本脚本另一个未完成的任务使用时为 IO_ERROR.
  • 编码视频的操作默认使用 H.264, codec: 'h265' 可选; 设备没有所需编码器时为 UNSUPPORTED_FORMAT. 视频码率省略时由插件按尺寸与帧率估算 (1080p 30 fps 的 H.264 约 8 Mbit/s, H.265 取其 0.6 倍).

默认输出#

省略输出路径时, 输出写到以下位置, 与插件界面工具箱的默认目录相同. 表中的 /sdcard 指设备的主共享存储.

输出 目录 文件名
视频加工结果 /sdcard/Movies/3-Slate Studio/ <源名>-<操作>-<yyyyMMdd-HHmmss>.mp4
extractAudio 与 audio 的加工结果 /sdcard/Music/3-Slate Studio/ <源名>-<操作>-<yyyyMMdd-HHmmss>.m4a (或 format 指定的扩展名)
thumbnail, toGif 与 frames /sdcard/Pictures/3-Slate Studio/ 缩略图 .jpg, GIF .gif, 抽帧为同名文件夹
录屏 video.record /sdcard/Movies/AutoJs6/ screen-<yyyyMMdd-HHmmss>.mp4
录音 audio.record /sdcard/Music/AutoJs6/ audio-<yyyyMMdd-HHmmss>.m4a (或 .wav)
  • <源名> 为第一个输入的文件主名, 没有单一来源的操作 (concat, compose, audio.mix) 为 slate; <操作> 为操作名, 例如 trim, toGif, audioMix.
  • 名称已被占用 (已有同名文件或文件夹, 或是本脚本未完成任务的输出) 时依次追加 -1, -2 等序号.
  • 加工结果在完成后登记到系统媒体库, 相册与音乐应用随即可见; video.frame 的临时图片与字幕文件不登记. 录制结果保存后同样经媒体扫描登记.
  • 插件设置页的 "输出目录" 只影响插件界面的工具箱, 不改变脚本的默认输出.

任务, 进度与取消#

  • 同步形态阻塞当前线程直至任务结束, 不能在 UI 线程调用 (抛出 INVALID_OPTIONS). UI 模式中请使用对应的 Async 形态, 它返回 Promise, 可以在 UI 线程调用, 错误以 MediaStudioError 拒绝 Promise.
  • options.onProgress(progress) 接收 MediaStudioProgress. 同步形态在调用线程上执行回调, Async 形态在脚本线程上执行; 同一任务的两次进度至少间隔 200 ms. 回调抛出的第一个错误在任务结束后抛出 (Async 形态以它拒绝 Promise).
  • 插件同时编码至多 2 个任务 (插件设置页的 "任务并发数" 可改为 1), 其余排队; 同一脚本未完成的加工任务至多 4 个, 第 5 个失败于 TASK_LIMIT. 插件设置页的 "硬件编码器偏好" 同样作用于脚本的任务.
  • 停止脚本或调用 video.cancelAll 会取消未完成的任务, 插件删除写到一半的输出, 调用以 TASK_CANCELLED 结束. 正在进行的录制在脚本停止时自动停止并保存.
  • video.tasks 列出本脚本的插件任务 (video 与 audio 共用一张表), 插件界面的 "任务" 页也显示它们.
  • 结果的 warnings 数组给出不中断任务的提示: OUTPUT_LARGE (输出或某个输入超过 2 GiB), DURATION_LONG (超过 60 分钟), 以及自由文本, 例如裁剪改为重编码, 混音被整体缩放, 转场被 GPU 回退替换.
  • AutoJs6 等待插件接受请求至多 10 秒 (probe 为 30 秒), 任务本身不限时长. 长任务运行满 10 秒后, 插件启动带进度通知的前台服务.

时间线 (Timeline)#

video.compose 按一个时间线对象合成视频: 多条视频轨与音频轨, 片段间的转场, 文字与图片叠加, 以及字幕. 插件界面的时间线剪辑器导出时使用同一管线, 其工程文件 (.slate.json) 就是这个对象加上界面状态, 剪辑器的结果页给出等价的 video.compose 代码.

let timeline = {
    width: 1280, height: 720, frameRate: 30, background: '#000000',
    video: [{
        clips: [
            { src: '/sdcard/Movies/a.mp4', start: 0, end: 8000 },
            { src: '/sdcard/Movies/b.mp4', start: 2000, end: 10000, transition: { type: 'dissolve', duration: 500 } },
        ],
    }],
    audio: [{
        clips: [{ src: '/sdcard/Music/bgm.m4a', end: 15500, volume: 0.4, fadeIn: 1000, fadeOut: 2000 }],
    }],
    overlays: [
        { type: 'text', text: 'Hello', from: 1000, to: 4000, x: '50%', y: '10%', fontSize: 48, stroke: '#000000' },
    ],
    subtitles: { src: '/sdcard/Movies/a.srt', style: { fontSize: 40 } },
};
let result = video.compose(timeline, { onProgress: p => console.log(p.stage, p.percent) });
console.log(result.path, result.durationMillis);

顶层键:

键 说明
width / height 输出尺寸, 16 - 8192, 向下取偶数. 省略时取第一条视频轨第一段经裁切与旋转后的尺寸
frameRate 输出帧率, 整数 1 - 120, 默认 30
background 无画面处的底色, 颜色写法同叠加的 color, 默认黑色
video 视频轨数组, 至多 8 条; 每条为 { clips: [...] }. 数组顺序即叠放顺序, video[0] 在最下层
audio 音频轨数组, 至多 16 条; 每条为 { clips: [...] }
overlays 叠加物数组, 写法同 video.overlay 的 overlays, 位于全部视频轨之上; 空数组表示无叠加
subtitles 字幕 { src, style? } 或 { cues, style? }, 写法同 video.burnSubtitles (style 不含 codec / bitRate), 画在叠加物之上

整个时间线至少有一个视频片段, 片段 (视频与音频合计) 至多 256 个.

键 说明
src 源文件的绝对路径 (脚本中可写相对路径, AutoJs6 先解析为绝对路径), 必需
start / end 取用的源区间, end 不含; start 默认 0, end 省略时到源结尾
at 片段在时间线上的开始位置; 省略时紧接同一轨道的上一段 (首段为 0)
speed 播放速度 0.25 - 8, 默认 1, 声音保持音高
volume 片段自带声音的音量, 线性倍数 0 - 16, 默认 1
transform { scale?, rotate?, crop?, flip?, fit? }: scale 大于 0 且至多 8, 默认 1; rotate 为 90 的倍数 (顺时针); crop 为 { x?, y?, width, height } (像素); flip 为 none, horizontal, vertical 或 both; fit 为 contain (默认), cover 或 stretch
transition 与上一段之间的转场 { type, duration?, direction? }, 见下表; 首段不能有转场

音频片段有 src, start, end, at 与 volume (含义同视频片段), 另有 fadeIn 与 fadeOut (淡入, 淡出的时长).

转场 (transition.type), 时长 duration 为 100 - 3000 ms, 默认 500:

类型 效果 与上一段重叠
cut 直接切换, 忽略时长 否
fade 先淡出到黑场, 再淡入, 两侧各占时长的一半 否
dissolve 叠化 是
slide 推移, direction 为 left (默认), right, up 或 down 是
wipe 擦除, direction 同上 是
zoom 上一段放大淡出, 本段由小放大 是
blur 模糊叠化 是

定位规则 (插件探测源文件之后检查):

  • 同一轨道的片段不能重叠, 只有带重叠转场的片段在上一段结尾之前 duration 开始; 这种片段若显式给出 at, 必须恰好等于该位置. 转场不能长于前后任一片段.
  • 片段之间的空档与全部轨道之外的时段显示 background, 并且无声. 输出时长为所有片段结尾的最大值.
  • 叠加物与字幕的时间按时间线计算.
  • 错误消息带有从 timeline. 起的字段路径, 例如 timeline.video[0].clips[1].at (1000) must be 2500 ...; 合成失败时不留下半成品文件.

GPU 回退: fade, wipe 与 blur 使用着色器, 设备的 GPU 处理失败时, 插件先把 wipe / blur 换成 dissolve, fade 换成 cut 重新导出, 仍失败则全部换成 cut, 每次替换都在结果的 warnings 中说明.

同时解码的来源: 带重叠转场的视频轨在转场期间同时解码前后两段, 因此一个时间线至多约有 8 x 2 + 16 = 32 个来源同时解码, 超出设备编解码器的能力时导出失败于 CODEC_ERROR, 消息给出估算的来源数并建议减少视频轨或重叠转场. 实测 Sony G8441 (Android 9), XQ-AT72 (Android 12) 与 XQ-DQ72 (Android 13) 上 6 条带重叠转场的视频轨加 16 条音频轨可以导出, 8 + 16 则失败.

合成的音轨与 audio.mix 一样分两遍处理: 各来源相加后会削波时整体缩放到 -1 dBFS, 并在 warnings 中报告峰值与缩放量; 不会削波时保持原电平.

字幕 (Subtitles)#

video.burnSubtitles, 时间线的 subtitles 与 video.subtitles 使用同一套字幕规则.

  • 字幕条目 (cue) 为 { start, end, text }: 时间为整数毫秒, end 大于 start; text 为 1 - 1000 个字符, 不能只有空白, 可以含 SRT 标记 (<b>, <i>, <u>, <font color>), 换行用 \n. 一个数组至多 10000 条.
  • 字幕文件至多 16 MiB, 编码为 UTF-8 (可带 BOM) 或带 BOM 的 UTF-16; 非法的 UTF-8 字节被替换并给出警告. 格式先按扩展名 (.srt / .ass / .ssa), 再按内容判断.
  • SRT: 容忍缺少序号, 缺少空行, 以句点分隔的毫秒与 CRLF 换行; 没有文本或结尾不晚于开头的条目被跳过并给出警告, 时间重叠的条目保留.
  • ASS (基础子集): 读取 [Script Info] 的 PlayResX / PlayResY 与 WrapStyle, [V4+ Styles] 或 [V4 Styles] (SSA 的对齐方式自动换算) 中的字体, 字号, 主色, 边框色, 背景色, 粗体, 斜体, BorderStyle (3 为底框), Outline, Shadow, Alignment 与边距, 以及 Dialogue 的时间, 样式与文本. 内联标签只认 \b, \i, \c / \1c, \fs, \an 与 \pos, 以及换行 \N, \n 与硬空格 \h; 绘图 (\p) 不显示, 卡拉 OK, 动画等其他标签被忽略, 汇总为一条警告. 3-Slate Studio 1.1.0 安装 FFmpeg 大库后, ASS 计划改用 libass 完整渲染.
  • 默认样式 (SRT 与条目数组): 字号为画面高度的 1/18, 白字黑边, 底部居中, 上下与左右边距为画面的 5%. ASS 按自身样式渲染, 字号与位置按 PlayResY 缩放到输出尺寸; style 中给出的键覆盖每个样式.
  • style 的键与文字叠加相同 (font, fontSize, bold, italic, color, stroke, strokeWidth, shadow, shadowRadius, shadowDx, shadowDy), 另有 background (每行文字后的底框颜色), align (锚点, 取值同叠加的 anchor, 默认 bottom), marginV 与 marginH (像素 0 - 4096 或百分比 '0%' - '50%').
  • 同一时刻显示的多条字幕不互相覆盖: 位于底部的按开始时间自下而上堆叠, 位于顶部的自上而下堆叠. 字幕画在叠加物之上.

Node.js 与 Bun#

Node.js 主线程与 Worker 通过 require('autojs6:video') / require('autojs6:audio') (或 $autojs.video / $autojs.audio) 使用本模块, Bun 通过 host.video / host.audio 使用 (Node.js Runtime 2.2.0, Bun Runtime 0.23.0 及以上). 成员, 参数, 选项, 结果与错误码同 Rhino, 但全部方法返回 Promise; 录制句柄的 stop, cancel, status 与 capture 也返回 Promise, capture 得到图片句柄, 由脚本回收. 参阅 运行时 API.

  • Node.js 按调用检查项目声明的能力: 加工方法, tasks 与 cancelAll 需要 media; video.record 需要 screen_capture, 录制声音时另需 media 与 media.recording; audio.record 需要 media 与 media.recording.
  • Bun 需要授权 mediastudio.control (默认关闭). 录屏另需 screen.capture 与 screen.record, 录制麦克风需要 screen.record.microphone, 内录需要 screen.capture 与 screen.record.playback, 与 Bun 的 host.screenRecorder 是同一组开关.
  • 录屏前同样要在同一次执行中先 await images.requestScreenCapture(). Node.js 的该调用受桥接调用 30 秒的等待上限约束: 用户 30 秒内没有在系统对话框中确认时, 调用以 ERR_AUTOJS6_BRIDGE_TIMEOUT 失败并关闭对话框, 应提示用户及时确认后重试. Bun 的 host.images.requestScreenCapture 可用 timeoutMs 指定等待时间, 参阅 Bun 截图与录屏授权.
  • 带 onStop 的录制在结束前保持执行; 执行结束时 AutoJs6 保存仍在进行的录制, 并取消本次执行未完成的加工任务.

packageName 插件包名
versionName / versionCode 插件版本
contractVersion 插件实现的契约版本, AutoJs6 6.8.1 要求为 2
ops 插件已实现的操作名数组

错误代码#

代码 含义
PLUGIN_UNAVAILABLE 没有安装 3-Slate Studio, 或无法连接
PLUGIN_DISABLED 插件已安装, 但在插件中心被禁用或未授权
PLUGIN_INCOMPATIBLE 插件版本或契约与当前 AutoJs6 不兼容
INVALID_OPTIONS 选项未知, 类型或取值范围错误, 缺少参数, 或同步方法在 UI 线程调用; 消息写明键名
LIMIT_EXCEEDED 超出上限 (输入个数, GIF 帧数, 抽帧数, 混音输入数, 时间线轨道与片段数, 字幕条目数), 共用屏幕捕获会话时的第二个录屏, 或请求过大
TASK_LIMIT 本脚本已有 4 个未完成的加工任务
UNSUPPORTED_FORMAT 输入或输出的容器, 编码或字幕格式不受支持, 设备缺少所需编码器, 输出扩展名与操作不符, 或 Android 9 及以下输出 OGG
CODEC_ERROR 编解码或封装失败, 包括设备编解码器资源不足
IO_ERROR 输入不能读取, 输出不能写入 (文件不存在, 输出已存在, 输出被其他任务占用, 存储空间不足)
STORAGE_PERMISSION_DENIED 插件没有 "所有文件访问" 权限
TASK_CANCELLED 任务被 cancelAll, 脚本停止或宿主断开取消
TASK_NOT_FOUND 没有该 ID 的任务
PERMISSION_DENIED 录制缺少截图会话, 或麦克风权限被拒绝或无法弹出授权对话框
INTERNAL_ERROR 其他错误, 包括插件进程退出, 应答异常与等待超时

限制#

项目 上限
同时编码 整个插件 2 个 (插件设置页可改为 1)
每个脚本未完成的加工任务 4 个
每个请求的输入 256 个
叠加物 每次 64 个, 每个文字 1000 个字符
抽帧 每次 1000 张
GIF 600 帧, 1 - 50 fps
时间线 视频轨 8 条, 音频轨 16 条, 片段 256 个, 帧率 1 - 120
字幕 每个数组 10000 条, 每条 1000 个字符, 字幕文件 16 MiB
速度倍数 0.25 - 8
转场时长 100 - 3000 ms, 默认 500
宽度与高度 16 - 8192, 向下取偶数 (录屏为 2 - 8192 的偶数)
视频码率 / 音频码率 / 帧率 100 kbit/s - 200 Mbit/s / 8 - 512 kbit/s / 1 - 120
时间 整数毫秒, 0 - 2^53
录制时长 24 小时 (maxDuration)
提示阈值 2 GiB 或 60 分钟 (warnings, 不是错误)
