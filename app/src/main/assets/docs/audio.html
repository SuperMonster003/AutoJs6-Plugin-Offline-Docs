音频 (Audio)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 audio autojs6:audio, $autojs.audio autojs6:audio, $autojs.audio host.audio
状态 已支持 20 项 已支持 20 项 已支持 20 项 需授权 20 项
授权 - - - mediastudio.control 20 项

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

audio 模块用于在脚本中录音 (麦克风, 内录或两者混合), 以及借助 3-Slate Studio 插件加工音频: 裁剪, 拼接, 混音, 音量与淡入淡出, 格式转换与变速. 录屏与视频加工见 视频 (Video).

本模块自 AutoJs6 6.8.1 起提供. 录音 (audio.record) 由 AutoJs6 自己完成, 不需要插件; 其余方法由 3-Slate Studio 插件 1.0.0 及以上版本执行. 插件的可用性, 参数约定, 默认输出, 任务与进度, 错误类型与限制和 video 模块相同, 两个模块共用同一张任务表, audio.MediaStudioError 与 video.MediaStudioError 为同一构造器:

  • 准备工作: 安装并启用 3-Slate Studio, 授予插件 "所有文件访问" 权限.
  • 参数约定: 必需参数之后的字符串为输出路径, 对象为选项, 两者顺序不限.
  • 默认输出: 加工结果默认写到 /sdcard/Music/3-Slate Studio/, 录音默认写到 /sdcard/Music/AutoJs6/.
  • 任务, 进度与取消, 错误代码, 限制.

本模块在 Rhino 中注册为全局名称 audio, 并提供 $audio 别名, 二者指向同一对象. 本页的签名与同步返回值描述 Rhino; Node.js 与 Bun 见 video 模块的 Node.js 与 Bun.

let mixed = audio.mix([
    '/sdcard/Music/voice.m4a',
    { src: '/sdcard/Music/bgm.mp3', volume: 0.3 },
]);
let out = audio.volume(mixed.path, { fadeOut: 3000 }, '/sdcard/Music/podcast.m4a');
console.log(out.path, out.durationMillis);

输入与输出格式#

输入可以是设备系统能解码的音频文件 (如 MP3, AAC / M4A, FLAC, Ogg, WAV, AMR), 也可以是带音轨的视频文件 (取其音轨); 没有音轨的文件为 UNSUPPORTED_FORMAT.

输出格式由 format 选项或输出路径的扩展名决定, 都没有时为 M4A:

格式 编码 说明
m4a AAC 默认; 码率默认单声道 128 kbit/s, 立体声 192 kbit/s
wav PCM 16 位 无损, 不接受 bitRate
flac FLAC 无损, 不接受 bitRate
ogg Opus 需要 Android 10 及以上, 更早的版本为 UNSUPPORTED_FORMAT; 采样率只能为 8000, 12000, 16000, 24000 或 48000, 默认 48000; 码率默认单声道 64 kbit/s, 立体声 96 kbit/s

未指定的参数按输入决定: 声道数为输入的声道数 (WAV 之外至多 2 声道); 采样率 WAV 与 FLAC 保留输入的采样率, M4A 取 AAC 支持且不低于输入的采样率; 多个输入时按其中最高的采样率与最多的声道数. 设备缺少所需编码器时为 UNSUPPORTED_FORMAT.

录音#

audio.record 在 AutoJs6 进程中录音, 与 video.record 共用同一个录制内核.

  • 音源 source: mic / microphone (默认), playback (内录, 录制其他应用播放的声音), mixed (麦克风与内录混在一条音轨). 三者都需要 AutoJs6 的麦克风权限; playback 与 mixed 另需 Android 10 及以上, 并像录屏一样需要截图会话, 先调用 images.requestScreenCapture, 否则失败于 PERMISSION_DENIED. 不允许被录制的应用的声音为静音.
  • 格式为 M4A (AAC) 或 WAV (PCM 16 位), 省略 format 时随输出扩展名, 都没有时为 M4A. 麦克风默认 48 kHz 单声道 128 kbit/s, 内录与混合默认 48 kHz 立体声 192 kbit/s.
  • 文件先以临时名写在目标旁边, 保存时才移入; 取消或失败的录音不留下文件. 显式输出已存在时为 IO_ERROR, 除非 overwrite 为 true.
  • 脚本停止时正在进行的录音自动停止并保存.
  • 插件的 "录音" 页面提供同样的录音功能, 并能生成等价的 audio.record 代码, 见 3-Slate Studio.
let rec = audio.record('/sdcard/Music/memo.m4a', { maxDuration: 60000, onStop: info => console.log('结束:', info.reason) });
sleep(5000);
let r = rec.stop();
console.log(r.path, r.durationMillis, r.audio.sampleRate);

[m] mix#

audio.mix(inputs, output?, options?)#

6.8.1 Non-UI

  • inputs { (string | AudioMixInput)[] } - 2 - 16 个输入, 每个为路径或带音量与偏移的对象
  • [ output ] { string } - 输出音频路径
  • [ options ] { AudioOutputOptions } - 输出格式与参数
  • returns { MediaStudioResult } - 加工结果

把多路声音混成一路. 每个输入可以设置音量 (volume, 线性倍数) 与在输出中的开始位置 (at); 输出时长为各输入结尾的最大值. 超过 16 个输入为 LIMIT_EXCEEDED.

混音分两遍处理: 各路相加后会削波时, 整体缩放到峰值 -1 dBFS, 并在 warnings 中报告峰值与缩放量 (例如 the mix peaked at +6.02 dBFS; it was scaled by -7.02 dB to -1 dBFS to avoid clipping); 不会削波时保持原电平, 不放大.

let r = audio.mix([
    { src: '/sdcard/Music/voice.wav', volume: 1 },
    { src: '/sdcard/Music/bgm.m4a', volume: 0.25 },
    { src: '/sdcard/Music/ding.ogg', at: 4000 },
], '/sdcard/Music/mixed.m4a');
r.warnings.forEach(w => console.warn(w));

[m] volume#

audio.volume(src, options, output?)#

6.8.1 Non-UI

选项 (Options)#

AudioRecordOptions#

audio.record 的选项.

键 类型 说明
source string 'mic' / 'microphone' (默认), 'playback' 或 'mixed', 见 录音
format string 'm4a' 或 'wav'; 省略时随输出扩展名, 都没有时为 m4a; 与扩展名不一致时为 INVALID_OPTIONS
sampleRate number 采样率 8000 - 192000 Hz, 默认 48000
channels number 声道数 1 或 2; 麦克风默认 1, 内录与混合默认 2
bitRate number AAC 码率 16000 - 320000 bit/s; 麦克风默认 128000, 内录与混合默认 192000
maxDuration number 最长时长 (毫秒), 0 (默认) 为不限, 至多 86400000 (24 小时); 到时自动停止并保存
overwrite boolean 显式输出已存在时是否覆盖, 默认 false
onStop Function 录音结束时在脚本线程执行一次, 参数见 RecordingStopInfo; 设置后脚本在录音结束前保持运行

AudioOutputOptions#

输出格式与参数, 也是 video.extractAudio 的选项. 各加工方法的选项对象都可以包含这些键与 onProgress.

键 类型 说明
format string m4a, wav, flac 或 ogg, 见 输入与输出格式
bitRate number 码率 8000 - 512000 bit/s; 不用于 wav 与 flac
sampleRate number 8000, 11025, 12000, 16000, 22050, 24000, 32000, 44100 或 48000 (ogg 只能为 8000, 12000, 16000, 24000 或 48000)
channels number 1 或 2
onProgress Function 进度回调, 见 任务, 进度与取消

AudioTrimOptions#

AudioOutputOptions 的键, 另有:

键 类型 说明
start number 开始时间, 默认 0
end number 结束时间 (不含); 与 duration 二选一, 都省略时到结尾
duration number 时长; 与 end 二选一

AudioMixInput#

键 类型 说明
src string 输入文件路径, 必需
volume number 线性音量倍数 0 - 16, 默认 1 (0.5 约为 -6 dB)
at number 在输出中的开始位置 (毫秒), 默认 0

AudioVolumeOptions#

AudioOutputOptions 的键, 另有以下键, 至少给出一项:

键 类型 说明
gain number 线性增益倍数 0 - 16; 与 normalize 互斥
normalize boolean 或 number 把峰值调整到目标电平: true 为 -1 dBFS, 数字为 -60 - 0 dBFS 的目标峰值; 与 gain 互斥
fadeIn number 淡入时长 (毫秒), 默认 0
fadeOut number 淡出时长 (毫秒), 默认 0

AudioSpeedOptions#

AudioOutputOptions 的键, 另有:

键 类型 说明
factor number 速度倍数 0.25 - 8, 必需
keepPitch boolean 是否保持音高, 默认 true

返回对象#

加工结果 MediaStudioResult, 媒体信息 MediaInfo, 进度 MediaStudioProgress, 任务 MediaStudioTask 与版本 MediaStudioVersion 见 video 模块.

AudioRecording#

audio.record 返回的录音句柄.

成员 说明
id 录音 ID
path 输出文件路径
stop() 停止并保存, 返回 RecordingResult
cancel() 停止并丢弃, 不留下文件, 返回是否取消了正在进行的录音
status() 返回 RecordingStatus (含 format 与不含暂停的 recordedMillis)
