表格查看器会话 (SheetViewSession)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 SheetViewSession 对象 autojs6:xlsx autojs6:xlsx host.xlsx
状态 已支持 19 项 已支持 19 项 已支持 19 项 需授权 19 项
授权 - - - xlsx.control 19 项

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

SheetViewSession 是 xlsx.view 返回的会话对象, 是 EventEmitter 的实例, 连接脚本与 3-Tally Sheet 插件中正在显示表格的查看器: 用户的选择以 select 事件在脚本线程到达, 脚本可以更新显示的内容, 移动选区, 读取查看器的状态并结束会话.

会话打开期间脚本保持运行, 不需要也不应使用 sleep 循环等待; close 事件是最后一个事件, 之后不再有事件, 脚本没有其他工作时随即结束. 脚本退出时未关闭的会话静默断开 (不触发 close 事件), 查看器留在前台由用户继续查看.

控制方法只有同步形态, 失败时抛出 XlsxError; 会话结束后 update, select 与 state 失败于 SESSION_CLOSED (消息为 "the viewer session is closed"). on, once 与除 state 外的控制方法返回自身以便链式调用.

查看器同时只显示一个会话, 之后的 xlsx.view (无论来自哪个脚本) 使之前的会话以 'replaced' 结束. 本脚本上一个会话仍在显示时, 新会话直接接手已显示的查看器 (就地替换), 查看器按新会话的选项重新显示, AutoJs6 在后台也可以; 其他情况下打开查看器要求 AutoJs6 在前台. 被替换的会话收到原因为 'replaced' 的 close 事件, 它与新的 xlsx.view 返回的先后不确定.

let session = xlsx.view('./orders.xlsx', { title: '订单', selectable: 'row', columns: ['A', 'C', 'E'] });
session.on('select', e => {
    console.log(e.sheet, e.row, e.col, JSON.stringify(e.values));
}).on('close', e => console.log('closed:', e.reason));

SheetViewSession

[@] SheetViewSession#

6.8.1

会话对象. 不能用 new 构造, 只由 xlsx.view 与 xlsx.viewAsync 产生.

会话按 xlsx.view 的第一个参数分为两种: 给出路径时显示文件 (文件会话), 给出行时显示内存表 (行会话). 行号与列号的含义见 事件.

[m#] update#

session.update(rows)#

6.8.1 Overload 1/2

  • rows { any[][] | object[] } - 新的行
  • returns { SheetViewSession } - 自身

用 rows 替换行会话显示的内存表, 列标题与列的规则沿用 xlsx.view 的 header 与 columns. 行数至多 1,048,576 (不含 header: true 时的表头行), 超出时失败于 LIMIT_EXCEEDED. 文件会话调用时失败于 INVALID_ARGUMENT.

调用返回后, state 立即反映新的行数与列数, 查看器随后重绘.

let rows = [['姓名', '分数'], ['甲', 92]];
let session = xlsx.view(rows, { header: true });
rows.push(['乙', 78]);
session.update(rows);
console.log(session.state().rows); // 2

session.update(path)#

6.8.1 Overload 2/2

  • path { string } - 文件路径
  • returns { SheetViewSession } - 自身

让文件会话改为显示 path, 以 xlsx.view 时的选项 (password, format, encoding 等) 打开. 行会话调用时失败于 INVALID_ARGUMENT.

[m#] select#

session.select(row)#

6.8.1

  • row { number } - 源行号, 从 1 计
  • returns { SheetViewSession } - 自身

把查看器的选区移到第 row 行, 列保持当前选中的列 (没有选区时为第一个显示的列), 必要时滚动到该行. 行号的含义同 select 事件的 row; 排序后仍指向原来的行.

  • 只移动选区, 不触发 select 事件 (select 事件只来自用户点按).
  • row 超出内容的行数时不移动选区. row 不是 1 至 1,048,576 的整数时失败于 INVALID_ARGUMENT.
  • 调用返回后, state 的 row 立即为请求的行. 紧跟 update(rows) 的 select 等新的行载入后才落到该行.

[m#] state#

session.state()#

6.8.1

  • returns {{
    • sheet: string | null;
    • row: number;
    • col: number;
    • rows: number;
    • cols: number;
    • token: string;
    • visible: boolean;
  • }}

向查看器查询当前状态:

  • sheet 为显示的工作表名称, 行会话为 'Sheet1'; 内容载入之前为 null.
  • row 与 col 为选中的源行号与列号 (含义同 select 事件), 没有选区时为 0.
  • rows 与 cols 为显示内容的行数与列数 (行会话不含表头行), 内容载入之前为 0.
  • token 为会话令牌.
  • visible 表示查看器当前是否在屏幕上可见.
let s = session.state();
console.log(s.sheet, s.rows + ' x ' + s.cols, s.row > 0 ? '选中第 ' + s.row + ' 行' : '没有选区', s.visible ? '可见' : '在后台');

[m#] close#

session.close(options?)#

6.8.1

  • [ options ] { { finish?: boolean }} - finish 默认 false
  • returns { SheetViewSession } - 自身

结束会话. 默认只断开: 查看器留给用户继续查看, 会话立即结束, 不触发 close 事件. finish 为 true 时同时关闭查看器, 随后触发原因为 'finished' 的 close 事件. 重复调用, 或会话已结束 (含被替换) 时调用, 不做任何事.

session.close(); // 查看器留给用户.
session.close({ finish: true }); // 同时关闭查看器.

[m#] on#

session.on(event, listener)#

6.8.1

  • event { string } - 事件名
  • listener { Function } - 监听器
  • returns { SheetViewSession } - 自身

注册监听器. once 形态相同, 只触发一次. 其余成员见 EventEmitter. 会话没有自己的定时器, getTimer 返回 null, 监听器在脚本线程同步调用.

在 Node.js 与 Bun 中, 会话同样具有 EventEmitter 的全部成员 (prependListener, emit, emitSticky, eventNames, listeners, getMaxListeners, setMaxListeners, getTimer 等), 行为与 AutoJs6 脚本相同. 见 运行时 API.

[m#] toString#

session.toString()#

6.8.1

  • returns { string } - SheetViewSession { open }, 结束后为 SheetViewSession { closed }

事件 (Events)#

事件 回调参数 说明
select ({ sheet, row, col, values }) 用户点按了单元格或行号. 只在 xlsx.view 的 selectable 不为 false 或 'none' 时触发
close ({ reason }) 会话已结束, 不再有事件. 原因: 'closed' (用户或系统关闭了查看器, 或插件进程退出), 'replaced' (之后的 xlsx.view 替换了本会话), 'timeout' (查看器 60 秒内未能显示), 'finished' (脚本调用 close({ finish: true }))

select 事件的各项:

  • sheet { string } - 工作表名称, 行会话为 'Sheet1'.
  • row { number } - 源行号, 从 1 计. 文件会话为工作表的行号; 行会话为数据行的序号, header: true 时的表头行不计. 用户排序后仍指向原来的行.
  • col { number } - 列号, 从 1 计. 文件会话为工作表的列号; 行会话为该列在显示的列中的序号 (给了 columns 时按其顺序). 点按行号时为第一个显示的列.
  • values { any[] } - 该行在查看器中显示的各列的值, 按显示的顺序, 日期为 Date. 编码后超过 256 KiB 时每个文本截到 1000 个字符, 仍超过时为 [].

事件对象都是普通 JavaScript 对象. 建议始终注册 close 监听器, 以便得知用户离开了查看器.
