PDF 文档对象 (PdfDocument)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 PdfDocument 对象 autojs6:pdf autojs6:pdf host.pdf
状态 已支持 25 项 已支持 25 项 已支持 25 项 需授权 25 项
授权 - - - pdf.control 25 项

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

PdfDocument 是 pdf.open 返回的文档对象, 对应插件进程中一份已打开的 PDF. 对同一文档多次读取信息, 文本, 搜索或渲染时, 用它可以省去每次调用重新打开与解析文件的开销, 也只需在打开时给一次密码.

每个方法都有同步形态与 Async 形态, 参数与结果完全一致, 规则同 pdf 模块: 同步形态阻塞当前脚本线程且不能在 UI 线程调用, Async 形态返回带 cancel() 的 Promise. 失败时抛出 (或拒绝为) PdfError.

文档已经打开, 因此方法不接受 password 选项 (给出时失败于 INVALID_ARGUMENT, 消息为 "PdfDocument.x takes no password; the document is already open"). 页码均按这份文档计, 从 1 起. 关闭后的调用失败于 SESSION_CLOSED (消息为 "the document is closed"); 文档关闭时仍在进行的调用同样以 SESSION_CLOSED 结束. 插件内同一文档的调用依次执行, 不同文档的调用可以并行.

let doc = pdf.open('./manual.pdf');
console.log(doc.toString()); // PdfDocument { path: /storage/emulated/0/.../manual.pdf }
console.log(doc.pageCount, doc.pageSize(1));
console.log(doc.search('battery').length);
doc.close();

[@] PdfDocument#

6.8.1

[m#] pageSize#

doc.pageSize(page)#

6.8.1

  • page { number } - 页码
  • returns { { width: number; height: number; rotation: number }} - 页面的宽与高 (磅) 及旋转角度

取 info 中该页的尺寸, 即 doc.info().pages[page - 1]. 页码超出范围时失败于 PAGE_OUT_OF_RANGE.

let size = doc.pageSize(1);
console.log(size.width + 'x' + size.height + ' pt', size.rotation);
doc.close();

6.8.1

  • [ pagesOrOptions ] { string | number | Array | {{
    • pages?: string | number | Array;

[m#] save#

doc.save(output?, options?)#

6.8.1

  • [ output ] { string | null } - 输出路径, 省略时使用 默认输出 (操作名为 save)
  • [ options ] {{
    • delete?: string | number | Array;
    • pages?: string | number | Array;
    • order?: number[];
    • rotate?: number | { { degrees: number; pages?: string | number | Array }};
    • onProgress?: Function;
  • }} - 页面操作
  • returns { PdfResult } - { path, pageCount, sizeBytes, warnings }

在一次写出中组合多种页面操作. 所有页码都按这份文档原来的页码计, 依次执行:

  1. delete: 删除这些页.
  2. pages: 只保留这些页.
  3. order: 按给出的顺序排列保留下来的页. 它必须是保留页原页码的一个排列, 否则失败于 INVALID_ARGUMENT.
  4. rotate: 顺时针旋转 (90 的倍数). 为数字时作用于全部保留页; 为 { degrees, pages } 时只作用于 pages 中的页.

不带任何选项时写出文档的副本. 删除了全部页时失败于 INVALID_ARGUMENT. 写出的文档不加密, 加密的文档须以所有者密码打开 (见 加密文档与密码).

let doc = pdf.open('./scan.pdf');
let r = doc.save('./scan-clean.pdf', {
    delete: '1',
    order: [3, 2, 4],
    rotate: { degrees: 90, pages: 3 },
});
console.log(r.pageCount); // 3 (原文档 4 页), 依次为原第 3, 2, 4 页.
doc.close();
