脚本化 Java#

Rhino 引擎提供了脚本化 Java 的便捷性.

注: 此章节参考并修改自 Auto.js Pro 及 Scripting Java.

注: ECMA 标准并未包含与 Java 的交互, 本章节所有功能均作为扩展功能而非语言标准使用.

访问 Java 包和类#

Rhino 定义了顶层变量 Packages, 可用于访问顶层 Java 包 (如 [ java / com ] 等).

typeof Packages === 'object'; // true
typeof Packages.java === 'object'; // true

为了便于访问, Rhino 提供了顶层包名前缀的快捷访问方式.

Packages.java === java; // true

注: AutoJs6 顶层化的包名前缀包括 [ android / androidx / java / javax / org / com / net / de / ezy / kotlin / okhttp3 ].

顶层方法 importPackage 及 importClass 可以像 import 语句一样导入包或类.

importPackage(java.io);
typeof File === 'function'; // true

上述示例相当于 Java 的导入声明语句 import java.io.*;

importClass(java.io.File);
typeof File === 'function'; // true

上述示例相当于 Java 的导入声明语句 import java.io.File;

const File = java.io.File;
typeof File === 'function'; // true

上述示例也可使用解构赋值方式导入 File 类: const {File} = java.io;

注: 配合 TypeScript Declarations 的 IDE 可能对解构赋值变量无法进行类型识别和代码智能提示.
因此建议使用原始变量声明方式导入需要使用的类.
对于 importClass 和 importPackage, 目前还未能实现类型识别和代码智能提示 (截至 2022 年 7 月).

访问扩展的包及类#

AutoJs6 的项目扩展库及项目依赖包均可直接访问.

/* 依赖包: implementation("joda-time:joda-time:2.10.14"). */
typeof org.joda.time.LocalDateTime.now; // "function"

/* 扩展库: implementation(project(":libs:org.opencv-4.5.5")). */
typeof org.opencv.core.Point; // "function"

官方插件导出的 Java 包#

6.8.1

自 AutoJs6 6.8.0 起, 一部分过去内置的 Java 库不再随 AutoJs6 安装包提供. 自 AutoJs6 6.8.1 起, 其中的 Pinyin4j, Apache Commons Lang3, Apache Commons IO 与 Jackson 由官方插件重新提供: 在插件中心安装并启用下表的插件后, 脚本照常以完整类名使用这些类 (也可以先 importClass 或 importPackage), 包名与类名都与原库相同, 写法与 AutoJs6 6.8.0 之前一样.

插件 插件版本 库 Java 包 代表类
Pinyin4j 1.4.0 及以上 Pinyin4j 2.5.1 net.sourceforge.pinyin4j PinyinHelper, format.HanyuPinyinOutputFormat
Java Libraries 1.0.0 及以上 Apache Commons Lang3 3.18.0 org.apache.commons.lang3 StringUtils, time.DateFormatUtils, builder.ToStringBuilder
Java Libraries 1.0.0 及以上 Apache Commons IO 2.8.0 org.apache.commons.io IOUtils, FileUtils, FilenameUtils
Java Libraries 1.0.0 及以上 Jackson 2.13.4.2 (jackson-databind 2.13.4.2, jackson-core 与 jackson-annotations 2.13.4) com.fasterxml.jackson databind.ObjectMapper, databind.JsonNode, core.JsonFactory, annotation.JsonProperty

表中的代表类省略了所在的 Java 包, 例如 time.DateFormatUtils 的完整类名为 org.apache.commons.lang3.time.DateFormatUtils. Java Libraries 中三个库的版本与 AutoJs6 6.7.0 内置的相同, 原有脚本无需修改; 各类的用法以库的官方文档为准.

let StringUtils = org.apache.commons.lang3.StringUtils;
console.log(StringUtils.isBlank('  ')); // true
console.log(StringUtils.capitalize('autojs6')); // Autojs6

importClass(org.apache.commons.io.FilenameUtils);
console.log(FilenameUtils.getExtension('a/b.tar.gz')); // gz

let mapper = new com.fasterxml.jackson.databind.ObjectMapper();
let tree = mapper.readTree('{"name": "AutoJs6", "version": 6}');
console.log(tree.get('version').asInt()); // 6
console.log(mapper.writeValueAsString(tree)); // {"name":"AutoJs6","version":6}

let PinyinHelper = net.sourceforge.pinyin4j.PinyinHelper;
console.log(PinyinHelper.toHanyuPinyinStringArray('汉'.charCodeAt(0))[0]); // han4

这些类由 AutoJs6 直接从插件的安装包加载, 在运行脚本的 AutoJs6 进程中执行, 调用时不启动插件进程. 不引用这些包的脚本不受影响.

注: Pinyin4j 插件 1.4.0 之前的版本只提供 pinyin4j 模块, 不导出 Java 包.

注: 与 AutoJs6 6.7.0 相同, Java Libraries 中的库经过 core library desugaring, 参数或返回值为 java.time 类型的方法使用的是脱糖后的 j$.time 类型.

插件不可用时#

插件未安装, 未授权, 在插件中心被关闭, 或已安装的版本没有导出该包时, 脚本无法使用这些类:

  • 引用类名本身不会立即出错 (Rhino 把找不到的名字当作 Java 包, typeof 得到 'object' 而不是 'function'), 调用方法, 用 new 构造对象或传给 importClass 时才出错.
  • 脚本因这类错误结束时, AutoJs6 在错误消息之后附带一条指引 (控制台与 toast 中都有), 指引的文字随 AutoJs6 的语言变化.
插件状态 指引的做法
未安装, 或已卸载 在 AutoJs6 > 插件中心 安装该插件
未获授权 在 AutoJs6 > 插件中心 授权该插件
在插件中心被关闭 在 AutoJs6 > 插件中心 启用该插件
已安装的版本没有导出该类 (如 Pinyin4j 1.3.x) 在 AutoJs6 > 插件中心 将该插件更新到上表的版本或更高版本

例如 Java Libraries 未安装时, 调用 org.apache.commons.lang3.StringUtils.isBlank('') 的脚本以错误结束, 其后的指引为 The Java class org.apache.commons.lang3.StringUtils is provided by the official plugin "Java Libraries", which is not installed. Install the plugin in AutoJs6 > Plugin center.

安装, 关闭或卸载插件后立即生效, 不需要重启 AutoJs6.

以下情况不附指引:

  • 脚本自己用 try...catch 捕获的错误.
  • 先取出方法再调用, 如 let f = org.apache.commons.lang3.StringUtils.isBlank; f(''): 错误消息只含变量名.

java.lang.Class.forName 按名字查找时找不到插件中的类, 请以完整类名引用或使用 importClass.

已不再内置的库#

下表的库自 AutoJs6 6.8.0 起不再内置, 也没有插件导出它们的 Java 包. 自 AutoJs6 6.8.1 起, 脚本用到其中的类并因此出错结束时, 错误消息之后说明该库已不再内置; 有替代模块时一并给出模块与提供它的插件, 例如 The Java class javax.mail.Session belongs to JavaMail, which AutoJs6 no longer includes since 6.8.0. Use the mail module instead, provided by the plugin "3-Stamp Mail" (AutoJs6 > Plugin center).

打包的应用#

用 AutoJs6 打包应用时, 可以把上表插件中的 Java 包一并带入生成的应用, 打包的应用在没有安装这些插件的设备上也能使用这些类:

  • 打包功能扫描项目中的脚本, 发现上表 Java 包中的名字 (如 org.apache.commons.lang3.StringUtils, importPackage(com.fasterxml.jackson.databind), 注释与字符串中的名字也算) 即从本设备已安装的插件带入对应插件的全部导出包. Pinyin4j 与 Java Libraries 都适用.
  • 名字在运行时才拼接出来 (如 Packages['org.apache.commons.' + 'lang3'].StringUtils) 时扫描无法发现. 此时在打包页面的 "支持库" 中勾选 "Java Libraries", 打包时带上该插件的全部 Java 包. 加密的脚本与超过 4 MB 的文件不扫描, 它们用到的类同样需要勾选此项. 勾选只对 Java Libraries 有效, Pinyin4j 的类请在脚本中写出完整类名.
  • 带入要求打包所用的设备上已安装并启用对应插件 (版本不低于上表). 插件未安装, 未授权, 被关闭或版本没有导出时打包照常完成, 打包成功的对话框列出未打包的 Java 包, 原因与做法, 处理后重新打包即可.

打包的应用运行时先使用带入的副本: 首次使用时解出到应用的私有目录并设为只读, 设备上已安装的插件不会取代它; 要换用新版插件中的库, 用新版插件重新打包. 没有带入时, 如果所在设备安装并启用了对应插件, 则使用该插件. 两者都没有时, 脚本以错误结束, 其后的指引说明需要在该设备上安装并启用插件及其最低版本 (打包的应用没有插件中心, 指引不提插件中心), 例如 The Java class org.apache.commons.lang3.StringUtils is provided by the official plugin "Java Libraries". Install and enable the plugin (1.0.0 or later) on this device. 打包的应用用到 "已不再内置的库" 时, 只说明该库已不再内置, 不给出替代插件.

与 Java 协作#

Rhino 提供了在 JavaScript 代码中 [ 创建 Java 类 / 调用 Java 方法 / 访问变量 ] 等能力.

Java 类及方法#

let builder = new java.lang.StringBuilder();
builder.append('foo');
builder.append('bar');
builder.toString(); // "foobar"

Java 类的静态方法及字段#

java.lang.Math.PI; // 3.141592653589793
java.lang.Math.cos(0); // 1

Java 重载方法签名#

new java.io.File("foo").listFiles.toString();

/* 代码结果 (共 5 行). */

// function listFiles() {/*
//     java.io.File[] listFiles(java.io.FileFilter)
//     java.io.File[] listFiles(java.io.FilenameFilter)
//     java.io.File[] listFiles()
// */}

JavaBean 属性#

读写方法符合以下命名规范的类称为 JavaBean:

/* 读方法. */
getXyz(): Type
/* 写方法. */
setXyz(Type value): void

以下 JavaBean 示例 (Student) 定义了 age 和 sex 属性:

public class Student {

    private int mAge;

    public int getAge() { return mAge; }
    public void setAge(int anAge) { mAge = anAge; }

    public String getSex() { return "male"; }

};

其中 age 属性可读写, 而 sex 属性只读.

在 JavaScript 代码中可通过实例成员访问属性及方法:

let stu = new Student();
stu.sex; // "male" - 相当于调用 stu.getSex().
stu.age = 33; /* 相当于调用 stu.setAge(33). */
stu.age; // 33
stu.getAge(); // 33

同样地, 对于属性类型为 boolean 类型的 JavaBean:

public class Student {

    private boolean mMale;

    public boolean isMale() { return mMale; }
    public String setMale(boolean value) { mMale = value; }

};

JavaScript 使用方式:

let stu = new Student();
stu.male; // false - 相当于调用 stu.isMale().
stu.male = true; /* 相当于调用 stu.setMale(true). */
stu.male; // true
stu.isMale(); // true

实现 Java 接口#

函数转换#

"ui";

ui.layout(
    <frame>
        <button id="btn" text="BUTTON"/>
    </frame>
);

let listener = new android.view.View.OnClickListener(function (view) {
    toastLog("clicked");
});
ui.btn.setOnClickListener(listener);

上述示例将 JavaScript 函数作为 Java 接口传入 OnClickListener 方法.
将函数作为接口使用的条件: 接口只有一个方法 (不可为 0 或多于 1 个) 且参数类型依次匹配.

对象转换#

若 Java 接口有多个方法, 则可传入一个 JavaScript 对象:

public interface OnAttachStateChangeListener {
    public void onViewAttachedToWindow(View v);
    public void onViewDetachedFromWindow(View v);
}

JavaScript 代码实现:

new android.view.View.OnAttachStateChangeListener({
    onViewAttachedToWindow(view) {
        toastLog('attached');
    },
    onViewDetachedFromWindow(view) {
        toastLog('detached');
    },
});

JavaAdapter 构造器#

注: 需要定义可复用的类, 字段或私有名时, 可以使用 class X extends JavaClass 写法, 参阅 类语法.

实现 Java 接口#

new JavaAdapter(android.view.View.OnAttachStateChangeListener, {
    onViewAttachedToWindow(view) {
        toastLog('attached');
    },
    onViewDetachedFromWindow(view) {
        toastLog('detached');
    }
});

实现多个 Java 接口#

/* 语法: new JavaAdapter(javaIntfOrClass, [javaIntf, ..., javaIntf,] javascriptObject). */

new JavaAdapter(android.view.View.OnAttachStateChangeListener, java.lang.Runnable, {
    onViewAttachedToWindow(view) {
        toastLog('attached');
    },
    onViewDetachedFromWindow(view) {
        toastLog('detached');
    },
    run() {
        toastLog('run');
    }
});

继承 Java 类并重写方法#

"ui";

ui.layout(
    <vertical>
        <frame id="container"/>
    </vertical>
);

let paint = new Paint();
/* android.view.View 构造器的参数. */
let viewParam = activity;
let view = new JavaAdapter(android.view.View, {
    onDraw(canvas) {
        /* 调用父类 View 的 onDraw 方法. */
        this.super$onDraw(canvas);
        canvas.drawRect(500, 500, 1000, 1000, paint);
    },
}, viewParam);

ui.container.addView(view);
