Ce plugin fournit le site complet de documentation hors ligne d'AutoJs6 6.8.0. Après l'installation et l'activation du plugin, AutoJs6 valide ces ressources et les sert directement depuis l'AssetManager du plugin via son chargeur privé de ressources WebView.

Le plugin ne possède pas d'interface autonome. Installez-le uniquement depuis une source fiable, puis sélectionnez Documentation hors ligne comme source dans AutoJs6.
